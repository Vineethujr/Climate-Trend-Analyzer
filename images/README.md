# Project Visual Assets & Screenshots

This directory stores project screenshots, visual assets, and diagrams for the application repository and documentation.

## Contents
* `screenshots/`: Visual snapshots of each application dashboard page:
  * `01_climate_overview.png`: Historical time series and distribution overview.
  * `02_trend_analysis.png`: Decadal trend line, confidence bands, and rate metrics.
  * `03_seasonal_analysis.png`: Monthly climatology and intra-annual patterns.
  * `04_anomaly_detection.png`: Z-score and IQR flagged points.
  * `05_predictive_modeling.png`: Chronological train/test split performance.
* `architecture_diagram.png`: System architecture and data flow diagram.
