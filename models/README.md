# Statistical & Predictive Models

This directory stores serialized models, fitted parameters, and benchmark regression weights.

## Contents
* `baseline_ols_model.joblib`: Serialized lightweight linear regression and autoregressive baseline model fitted on chronological training splits.
* `model_metadata.json`: Provenance metadata recording training date ranges, feature formulas, training evaluation metrics, and model limitations.

## Principles
* Models in this repository serve strictly as reproducible educational baselines.
* No opaque uninterpretable deep neural networks or fabricated projections are used.
